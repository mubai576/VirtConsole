# VirtConsole 前端交互测试用例

- 依据：[docs/V1.0-UI与功能设计.md](V1.0-UI与功能设计.md)（焦点与返回模型、各 Tab 交互规范）
- 用途：作为 `frontend/test/driver.js` 测试套件的实现蓝本
- 约定：
  - **P0**：核心状态机/不变量，必须覆盖；**P1**：主要交互路径；**P2**：边缘/错误路径
  - **全局不变量**（每个用例步骤后校验）：全屏 ≤1 个 `.focused` + ≤1 个 Tab 栏高亮 + ≤1 个 active 视图
  - 后端依赖：`mock`（离线）/ `real`（真实 PVE）/ `ui`（仅界面，无后端依赖）

---

## 实现说明

- 用 `frontend/test/framework.js` 的 `step/assert/assertSingleFocus` 实现；键盘发给 `document.activeElement`，点击行定位内部焦点。
- 优先级顺序：**P0 先行**（A、C、F、G、H、J、I 核心），再补 P1/P2。
- 依赖 `mock` 的用例用 `mock://` 后端跑（离线确定性）；`real` 用例在真机 `VIRTCONSOLE_TEST=1` 验证。
- 破坏性用例（C12-C15）仅在 mock 后端执行。
