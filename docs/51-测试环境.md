## 一、凭据放在仓库外

**不要把密码写进 `docs/`。** 凭据放在项目根目录下未追踪的 `.secrets/testenv.env`
（`.gitignore` 已忽略 `.secrets/`）：

```bash
# .secrets/testenv.env  —— 不提交，chmod 600
VC_TEST_HOST=192.168.0.20
VC_TEST_USER=root
VC_TEST_PASSWORD=<改成实际密码>
```

用法：

```bash
set -a; . ./.secrets/testenv.env; set +a
ssh "${VC_TEST_USER}@${VC_TEST_HOST}"
```

> **历史提醒**：该密码曾以明文提交过，仍在 git 历史中。是否清理历史（需要重写历史，
> 破坏性）与是否轮换密码，由维护者决定。本次整理只做了「新文档不再包含明文」。

推荐改用 SSH 公钥登录，之后连 `VC_TEST_PASSWORD` 都不需要。

### Windows 开发机上的非交互登录

上面那条 `ssh` 在本机 git bash 里会卡在交互式密码提示：没有 `sshpass`、没有 `plink`、
也没有本地密钥。用 `scripts/testenv_rsh.py`（paramiko，密码只从 `.secrets/testenv.env` 读）：

```bash
export PY="/c/Users/s1973/AppData/Local/Python/pythoncore-3.14-64/python.exe"
export PYTHONIOENCODING=utf-8 PYTHONUTF8=1     # 远端输出是 UTF-8，不设就是乱码
MSYS2_ARG_CONV_EXCL='*' "$PY" scripts/testenv_rsh.py 'systemctl is-active virtconsole'
MSYS2_ARG_CONV_EXCL='*' "$PY" scripts/testenv_rsh.py --put target/x.tgz /root/x.tgz
```

两个必须项，少一个就会浪费时间在假故障上：

- **`MSYS2_ARG_CONV_EXCL='*'`**：否则 MSYS 把远端路径 `/tmp/x` 改写成 Windows 路径，
  paramiko 报 `FileNotFoundError`，看起来像远端没有该目录。
- **用绝对路径的 `python.exe`**：PATH 里的 `WindowsApps\python` 是 Microsoft Store 存根，
  会静默挂住（连 `print(1)` 都超时）。

真机没有 node、没有 git、也没有仓库 checkout：前端产物只能在本机 `npm run build`
后打包上传，再在真机 `cargo build --release`。

## 三、常用操作

```bash
# 服务状态与日志
ssh root@192.168.0.20 'systemctl status virtconsole-weston virtconsole'
ssh root@192.168.0.20 'journalctl -u virtconsole -f'
```

真机回归（**会短暂占用 HDMI**，测完自动退出并恢复服务）：

```bash
systemctl stop virtconsole
XDG_RUNTIME_DIR=/run/virtconsole WAYLAND_DISPLAY=wayland-0 GDK_BACKEND=wayland \
  VIRTCONSOLE_TEST=1 VIRTCONSOLE_TEST_SUITES=terminal /usr/local/bin/vc-ui
echo "exit=$?"
systemctl start virtconsole
```

套件名与退出码见 [40-测试规范.md](40-测试规范.md)。

## 四、部署新版本

```bash
# 构建机：前端产物必须先于 cargo build
cd ui/web && npm ci && npm run build && cd ../..
cargo build --release -p vc-ui

# 推送并替换
scp target/release/vc-ui root@192.168.0.20:/tmp/vc-ui
ssh root@192.168.0.20 'systemctl stop virtconsole \
  && install -m 0755 /tmp/vc-ui /usr/local/bin/vc-ui \
  && systemctl start virtconsole'
```
