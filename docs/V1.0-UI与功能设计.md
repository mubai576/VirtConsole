# V1.0 UI 与功能设计（大屏终端）

- 文档版本：V0.2（完成一轮评审修订）
- 日期：2026-08-07
- 范围：V1.0 大屏终端全部页面的 UI 设计 + 功能设计（阶段 A：PVE 运维闭环；阶段 B：宿主终端 / 画面模式）
- 明确不做：手机端 UI；**手机遥控 V1.0 不实现**（协议与配对页设计保留，另出文档）

---

## 一、设计目标与原则

1. **十英尺 UI**：远距离可读——标题 ≥20px、正文 ≥16px、高对比；全程方向键可达，零鼠标依赖。
2. **焦点模型统一**：任何时刻屏幕上只有一个高亮焦点；Enter 确认、Esc 逐层返回、Home 回首页。
3. **一致性**：全系统同一套组件语言（卡片 / 列表行 / 状态徽标 / 确认对话框 / 对话框输入 / Toast / 标签页条）。
4. **沉浸模式**：控制台（VM 画面）与终端为全屏沉浸模式，隐藏 Tab 栏与顶栏，统一 `Ctrl+Alt+Q` 退出。
5. **扁平化视觉（Apple / Xiaomi 风格）**：大圆角卡片、克制的弱投影、半透明毛玻璃层、系统级色彩 token；**支持明暗双模式**（手动切换 + 跟随系统）。
6. **无 Node / 无 CDN**：前端保持纯 HTML/CSS/JS；第三方库（xterm.js、二维码）本地 vendor，不依赖外网。

## 二、信息架构（顶部 Tab 导航）

顶栏常驻 Tab 条，全系统唯一一级导航。**低频功能（监控 / 终端）不作为一级 Tab**——它们天然是"按实体"（宿主机或某台 VM）的视图，下沉到虚拟机 Tab 的实体页内，与 PRD 2.1.1/2.1.2/2.1.4 对齐：

```
首页 · 虚拟机 · 浏览器 · 设置
```

| Tab | 职责 | PRD 对应 |
|---|---|---|
| 首页 | 状态总览仪表 + VM 快速卡片 + 快捷入口（宿主机迷你监控，仅查看） | 2.1.1 状态监控 |
| 虚拟机 | **实体枢纽**：宿主机 + 各 VM 的列表 → 实体页（二级视图按实体：VM=概览/监控/操作，宿主机=概览/监控/终端；VM 另含控制台） | 2.1.1 / 2.1.2 / 2.1.4 |
| 浏览器 | 地址栏 + 快速链接 + 标签条（复用现有实现） | 2.1.3 |
| 设置 | 主题 / 分辨率 / 采集 / PVE / 开机直连 / 系统信息 / 关于 | 2.2 |

### Tab 定义与可扩展性（数据驱动注册表）

**原则**：Tab 栏由注册表数据驱动，每个 Tab 是独立自包含模块；全局导航只做路由、不做业务分支。增删一个 Tab 只动一处，不改导航 / 焦点 / 键盘框架。

**前端注册表** `frontend/tabs/index.js`：

```js
// 统一 Tab 接口契约：
// { id, label, icon?, enabled(ctx)?, mount(el, ctx)?, unmount()?, onKey(e)?, focus()? }
// 注意：监控 / 终端不是一级 Tab，它们是"虚拟机" Tab 内实体页的二级视图（见 4.2/4.3/4.4）
import home from "./home.js";
import vm from "./vm.js";
import browser from "./browser.js";
import settings from "./settings.js";

export const TABS = [home, vm, browser, settings];
```

| 字段/方法 | 必选 | 说明 |
|---|---|---|
| `id / label / icon` | 必选 | 唯一 id、Tab 文字、图标 |
| `enabled(ctx)` | 可选 | 条件显示（默认 true）；`ctx` 来自 Rust `capabilities` 命令 |
| `mount(el, ctx)` | 必选 | 进入时把视图渲染进内容容器，负责自身焦点初始化 |
| `unmount()` | 可选 | 退出时清理（停轮询 / 杀子进程 / 关 Webview 标签） |
| `onKey(e)` | 可选 | 键盘分发，返回 `true` 表示已消费；未消费交给 Tab 栏/全局 |
| `focus()` | 可选 | 重新聚焦到上次位置 |

**全局键盘路由**（app.js 收敛为）：

```js
document.addEventListener("keydown", (e) => {
  if (current.onKey && current.onKey(e)) return;   // 当前 Tab 优先
  if (tabbar.handle(e)) return;                     // Tab 栏：←→ 切换 / Home / ↑ 返回
  handleGlobal(e);                                  // 全局：Esc 逐层返回等
});
```

**Rust 侧能力探测**（前端 `enabled(ctx)` 依据）：

```rust
// ui/src/capabilities.rs（示意）
#[tauri::command]
fn capabilities() -> serde_json::Value {
    json!({
        "terminal": has_pty_support(),   // PTY / 权限可用
        "pve": pve_configured(),         // PVE 连接已配置
        "remote": true,                  // 遥控服务可启动
    })
}
```

**增删成本**：

| 操作 | 改动点 |
|---|---|
| 新增 Tab | 写 `frontend/tabs/<id>.js` 一个模块 + 注册一行；必要时 Rust 加对应后端与能力位 |
| 删除 Tab | 移除注册一行（关联后端保留无害） |
| 临时隐藏 | `enabled(ctx)` 返回 false（如终端无权限、遥控未开启），注册表不动 |

**当前建议（固定 4 Tab）**：首页 / 虚拟机 / 浏览器 / 设置。监控与终端为虚拟机 Tab 内实体页的二级视图（不占一级入口）；手机遥控仅作"设置 → 配对页"（**V1.0 不实现**）。后期任一需求要升一级入口，加一个模块 + 注册一行即可。

### 焦点与返回模型（全局状态机）

```
层次:  Tab 内容区 → 实体列表 → 实体页 → 二级视图(监控/终端/操作) → 控制台/对话框
状态:  tab_focus(顶栏)  ⇄  content_focus(当前 Tab 内部)
```

- **Tab 栏焦点态**：←→ 切换 Tab，`↓` 或 `Enter` 进入内容区。
- **内容区**：组件间 ←→↑↓ 导航，Enter 确认。
- **实体页二级导航**：实体页顶部横向焦点条，←→ 切换二级视图（按实体：VM=概览/监控/操作，宿主机=概览/监控/终端）。
- **返回**：二级视图 → 实体页 → 实体列表（Esc 逐级）；内容区 → Tab 栏（`↑` 到顶部或 `Home`）；Home 一键回首页 Tab。
- **对话框**：Esc 取消，←→ 在按钮间移动，Enter 确认。
- **统一退出键 `Ctrl+Alt+Q`**：所有应用/沉浸模式（控制台、终端、浏览器）的**唯一退出快捷键**，等效"退出当前模式返回上一级"；Esc 按场景另有语义（详见各页）。
- **沉浸模式**：控制台 / 终端全屏内 `Ctrl+Alt+Q` 退出到进入前的实体页。

| 状态徽标 | ● 运行中(绿) · ⚠ 已暂停(琥珀) · ○ 已停止(灰) · ◐ 启动中/关闭中(青) |
| 迷你条 / 环形 | 纯 CSS 或 Canvas，无图表库；数值大字号显示 |
| 确认对话框 | 标题 + 描述 + [取消][确认]，确认默认聚焦；危险操作（关机/回滚）确认用红色 |

| Toast | 沿用现有，仅提示信息 |
| 空态 | 无 VM / 未连接 PVE / 连接失败时给出中文说明 + 重试按钮 |

## 四、各 Tab 详细设计

### 4.1 首页（状态总览）

```
┌────────────────────────────────────────────────────────────┐
│  宿主机状态   CPU ▓▓▓░░ 42%  内存 ▓▓▓▓░ 61%  磁盘 ▓▓░░ 55% │
│              GPU RTX 5070 Ti  利用 12% · 温度 51°C          │
├────────────────────────────────────────────────────────────┤
│  虚拟机                                   快捷              │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐  [浏览器] [设置]   │
│  │ VM 9000  │ │ VM 100   │ │ VM 200   │                    │
│  │ ● 运行中 │ │ ⚠ 已暂停 │ │ ○ 已停止 │                    │
│  │ CPU 5%   │ │ CPU 0%   │ │ —        │                    │
│  └──────────┘ └──────────┘ └──────────┘                    │
└────────────────────────────────────────────────────────────┘
```

- 数据源：PVE REST `/nodes/{node}/status`、`/cluster/resources?type=vm`（每 3–5s 轮询）。
- 焦点：VM 快速卡片间 ←→ 移动，Enter 进入该 VM 实体页（**跨 Tab 深链**，切到虚拟机 Tab）；快捷入口聚焦可达（同为深链）。
- 终端不放在首页快捷（低频功能，入口在 虚拟机 Tab → 宿主机实体页 → 终端视图）。
- 未连接 PVE：整块显示"未连接 PVE" + [设置连接] 跳转设置 Tab。

### 4.2 虚拟机（实体枢纽：宿主机 + 各 VM）

**实体列表**（宿主机作为"实体 0"，与 VM 同级列表）：

```
│ ▼ 实体列表                                              [刷新] │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │  宿主机   pve · PVE 9.2           ● 运行中  CPU 42% ▓▓▓░░ │ │
│ │  VM 9000 · Ubuntu 桌面   ● 运行中   CPU 5%  ▓▓░░  MEM 58%│ │
│ │  VM 100  · Windows 11    ○ 已停止   —                   │ │
│ │  VM 200  · Debian Server ⚠ 已暂停   CPU 0%  ▓░░░  MEM 12%│ │
│ └──────────────────────────────────────────────────────────┘ │
```

- 数据源：`/cluster/resources?type=vm` + `/nodes/{node}/status` 合并为实体列表（轻量轮询 3–5s）。
- `Enter` → 对应实体页。宿主机页与 VM 页用同一套实体页模板。

**实体页**（选中实体后，顶部二级导航；以 VM 为例）：

```
│ ◀ 返回   VM 9000 · Ubuntu 桌面       ● 运行中               │
│  概览 │ 监控 │ 操作                 ← 二级导航（←→ 切换）│
├────────────────────────────────────────────────────────────┤
│  概览: 配置（CPU/内存/磁盘/显卡→采集模式）· 快照列表        │
│  监控: 实时指标 + 曲线（见 4.3）                            │
│  操作: [进入控制台] [关闭] [重启] [快照]                    │
└────────────────────────────────────────────────────────────┘
```

- 二级导航**按实体差异**：VM = 概览 / 监控 / 操作（V1.0 无终端视图）；宿主机 = 概览 / 监控 / 终端（无操作、无控制台）。
- 二级导航交互：实体页顶部横向焦点条，←→ 切换二级视图；Esc 从二级视图回实体页，再 Esc 回列表。
- **操作视图**（仅 VM）：
  - **进入控制台**：沉浸模式（复用现有 QMP 全屏 Canvas），顶部角标显示采集模式；`Ctrl+Alt+Q` 退出。
  - **关闭**：优雅关机（PVE `shutdown`）→ 确认对话框；强制关闭 `stop` 为红色危险项（隐藏于"更多"）。
  - **重启**：确认对话框。
  - **快照**：创建（弹出命名对话框，自动填充时间戳）；回滚 / 删除需确认。
  - 动作执行中：按钮禁用 + 状态徽标"◐ 启动中/关闭中"；失败 Toast 展示 PVE 错误。
- **画面模式徽标**：依据 VM 显卡配置显示"模式 1 QMP 办公 / 模式 2 DMABUF 60fps / 模式 3 直通满血"；V1.0 仅模式 1 可实际操作，其余标注"待 V2.0/V3.0"。

### 4.3 监控（实体二级视图）

实体页内"监控"视图，按当前实体展示对应指标——**同时覆盖宿主机监控与 VM 监控**。

**宿主机监控指标：**

| 指标 | 数据源 |
|---|---|
| CPU 总使用率 / 负载 / 每核 | `/nodes/{node}/status`、`/nodes/{node}/rrddata?timeframe=hour`（历史曲线） |
| 内存 / 交换 | 同上 |
| 磁盘：各挂载点容量、IO 读写速率 | `df` 映射 `/nodes/{node}/disks`（容量）；`/rrddata`（IO） |
| 网络：各网口上下行速率 | `/nodes/{node}/rrddata` 或 `/nodes/{node}/network` |
| GPU：利用率 / 温度 / 显存 / 功耗 | `nvidia-smi --query-gpu=...`（子进程或 REST） |

```
│ ▼ 宿主机监控 · node: pve                                     │
│  CPU ▓▓▓░░ 42%   内存 ▓▓▓▓░ 61%   交换 ▓░░░░ 8%             │
│  磁盘 / 38G/85G  /var 12G/40G      网络 ↑ 1.2M/s ↓ 45K/s     │
│  GPU RTX 5070 Ti  利用 12% · 51°C · 显存 0.4/16G             │
│  [←→ 切换指标]  [Enter 放大为曲线]                           │
└────────────────────────────────────────────────────────────┘
```

**VM 监控指标（虚拟化层外部观测）：**

| 指标 | 数据源 |
|---|---|
| CPU 占用 %（占宿主总核） | `/nodes/{node}/qemu/{vmid}/status/current` |
| 内存（balloon / 已分配 / 已用） | 同上 + QMP `query-balloon` |
| 磁盘读写速率 | QMP `info blockstats` |
| 网络上下行速率 | QMP `info network` / PVE `netin` `netout` |
| 运行状态 | `/status/current` |
| 历史曲线 | `/nodes/{node}/qemu/{vmid}/rrddata?timeframe=hour` |

> 边界说明：VM 指标来自虚拟化层，**拿不到 VM 内进程级数据**；需要更细粒度时后续接 qemu-guest-agent（V1.0 不做）。

- 交互：←→ 切换指标，Enter 放大为整区曲线（纯 Canvas 绘制，首版 CPU/内存两条即可）。

### 4.4 终端（宿主机 shell，实体二级视图）

实体页内"终端"视图。**V1.0 仅宿主机 shell**；VM 终端（串口控制台）待 V2.0+。

| 实体 | V1.0 | 说明 |
|---|---|---|
| 宿主机 | ✅ | Rust PTY → `/bin/bash`（PRD 2.1.2） |
| VM | ⛔ 待 V2.0+ | 复用 PVE serial console（`qm terminal` 机制连 VM 串口）；V1.0 VM 实体页不显示"终端"二级视图 |

```
│ ▼ 终端 · root@pve · bash                     [退出终端]      │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ root@pve:~# uname -a                                    │ │
│ │ Linux pve 7.0.2-6-pve #1 SMP PREEMPT_DYNAMIC ...         │ │
│ └──────────────────────────────────────────────────────────┘ │
```

- 前端：xterm.js（**本地 vendor，无 CDN**，kiosk 离线可用）。
- 后端：Rust `portable-pty` 或 `forkpty` 运行 `/bin/bash`（V1.0 以 root 单会话，后续降权）；stdout→事件 / stdin←IPC。
- 退出：沉浸全屏 + 统一退出键 `Ctrl+Alt+Q`（见 2.x 焦点模型）；Esc 交给终端自身（避免吞掉终端内按键）。
- 生命周期：进入终端视图才建立会话，退出即销毁；崩溃自动重启并提示。
- 安全：仅本地回环监听，绑定远程地址需走设置开关。

### 4.5 浏览器

- 复用现有实现（地址栏 + 快速链接 + 标签条 = 独立 Webview 窗口），将入口从 overlay 迁移为 Tab 内容区。
- 退出：统一 `Ctrl+Alt+Q` 关闭全部标签并退出（**Webview 注入脚本同步监听该键**，替代现有 Esc 逻辑）；Esc 在地址栏/标签页场景保留原语义。
- 遗留：自签证书 https 警告页处理（V1.0 标记待解决）。

**设置项详表：**

| 设置项 | 取值 | 作用 / 实现 |
|---|---|---|
| 主题 | 深色 / 浅色 / 跟随系统 | 切换 `<html data-theme>` 的 CSS 变量；跟随系统用 `prefers-color-scheme` 默认分支 |
| 显示分辨率 | 720p / 1080p / 2K / 4K / 自动 | **UI 缩放（分辨率基准）**：本质是 UI scale factor，按 `rem` 基准整体缩放；物理像素随 HDMI 屏 EDID 全屏输出；自动 = 适配当前屏 |
| 画面采集 · 帧率 | 5 / 10 / 15 fps | QMP screendump 轮询间隔（模式 1，`ui/src/qmp.rs` 采集循环参数） |
| 画面采集 · 缩放 | 原始 / 适配屏幕 / 自定义 | VM 画面到 Canvas 的缩放策略（沿用 `display_source::blit_rgb` 的信箱模式） |
| PVE 连接 | 节点 + API Token 或 用户名密码 | 两种鉴权均支持（见 5.2），[测试连接] 校验 `GET /version` |
| 开机直连 | VMID 或 关 | 持久化替代环境变量 `VIRTCONSOLE_AUTOCONNECT_VMID` |
| 手机遥控 | 开关 / Token / 端口 | **V1.0 不实现**（端口可配置，设计保留，见 5.4） |
| 系统信息 | 版本 / 平台 / 架构 | 只读 |
| 关于 | 版本 / 构建 | 只读 |

## 五、功能设计（Rust 侧模块）

### 5.1 新增模块划分

| 模块 | 职责 | 新增文件 |
|---|---|---|
| `config` | PVE 连接配置、开机直连、遥控开关/Token/端口、**主题（明暗/跟随）、UI 渲染分辨率、采集帧率与缩放**的持久化（`config.json`） | `ui/src/config.rs` |
| `pve` | PVE REST 客户端（ticket/Token 鉴权、实体列表、VM 配置/动作/快照、节点与 VM 实时状态、rrddata） | `ui/src/pve.rs` |
| `terminal` | 终端会话：宿主机 PTY（bash，V1.0）；VM 串口（serial console，V2.0+ 规划）共用 stdout→事件 / stdin←IPC 传输抽象 | `ui/src/terminal.rs` |
| `remote` | 手机遥控 WebSocket 服务器（Token 鉴权、指令路由、设备会话管理） | `ui/src/remote.rs` |
| 前端 | Tab 框架重构 + 各 Tab 视图 JS | `frontend/*` |

### 5.2 PVE REST 接入层

- 鉴权：**API Token 与用户名密码两种方式均支持**——
  - API Token：`Authorization: PVEAPIToken=user@realm!tokenid=uuid`
  - 用户名密码：`POST /api2/json/access/ticket` 取 ticket + CSRF cookie
  - 设置页选择方式并输入，配置存 `config.json`。
- 端点清单（V1.0）：
  - `GET /cluster/resources?type=vm` — 实体列表（VM 实时 CPU/内存/状态，3–5s 轮询）
  - `GET /nodes/{node}/status` — 宿主机 CPU/内存/交换/负载
  - `GET /nodes/{node}/qemu/{vmid}/status/current` — VM 实时资源
  - `GET /nodes/{node}/qemu/{vmid}` — VM 配置（显卡→采集模式判定）
  - `POST /nodes/{node}/qemu/{vmid}/status/{start|stop|shutdown|reboot}`
  - `GET/POST/DELETE /nodes/{node}/qemu/{vmid}/snapshot[...]`、`rollback`
  - `GET /nodes/{node}/rrddata?timeframe=hour` — 宿主机历史曲线
  - `GET /nodes/{node}/qemu/{vmid}/rrddata?timeframe=hour` — VM 历史曲线
  - `GET /nodes/{node}/pveversion`
- 错误处理：连接失败 / 401 / 动作失败 → 中文 Toast + 状态点变红；轮询失败不打断 UI。
- 开发机 Mock：本地 tiny-http mock server 返回固定 JSON，UI 可离线开发（沿用 Mock 原则）。

### 5.3 QMP 与画面模式（现状复用）

- 保留 `ui/src/qmp.rs` 单连接串行化模型；控制台入口统一从 VM 实体页·操作视图 与 首页 VM 卡片进入。
- 采集模式判定：读 VM 配置的显卡类型 → 显示徽标；V1.0 实际仅模式 1 接通。

### 5.4 手机遥控（大屏侧，V1.0 不实现）

> **V1.0 决定延后实现**（用户确认：遥控端口可配置，功能先不做）。协议与配对页设计保留，端口默认 8899、可配置。

- 协议：`ws://<ip>:<port>`，首个消息带 Token，超时未鉴权断开。
- 指令集（V1.0 规划）：VM 启停/重启/快照、切 Tab、进入/退出控制台、控制台键鼠透传、终端指令、系统状态查询、浏览器开标签。
- 鉴权与设备管理状态存 `remote` 模块；配对页读取展示。手机端 UI 与协议详细字段另出文档。

### 5.5 终端

- 会话生命周期：进入宿主机实体页"终端"视图时建立，退出视图 / 应用退出时销毁；崩溃自动重启（保留提示）。
- 后端：宿主机 PTY（`portable-pty` 或 `forkpty`，V1.0 以 root 单会话，后续降权）；VM 串口（serial console）为 V2.0+ 规划。
- 编码：UTF-8；颜色与全键盘支持依赖 xterm.js 内置能力。

## 六、视觉规范（Apple / Xiaomi 扁平化 + 明暗双模式）

### 6.1 设计语言

- **扁平化**：无重阴影、无渐变贴图；层级靠"背景明度差 + 1px 描边 + 极淡阴影"表达
- **大圆角**：卡片 16–20px；按钮 12px
- **毛玻璃**：顶栏 / 悬浮层 / 沉浸模式状态栏用 `backdrop-filter: blur(20px)` + 低透明度表面色
- **系统级色彩**：Apple system palette 为基准的 token 体系，明暗两套，`[data-theme]` 一键切换
- 品牌字标"VIRTCONSOLE"可做渐变字（强调色系），其余元素保持扁平

### 6.2 色彩 token

| Token | 深色 | 浅色 |
|---|---|---|
| `--bg`（页面底） | `#0d0d12` | `#f5f5f7` |
| `--surface`（卡片） | `#16161d` | `#ffffff` |
| `--raised`（浮层/顶栏） | `#1e1e28` | `#fafafa` |
| `--text`（主文字） | `#f5f5f7` | `#1d1d1f` |
| `--text-2`（次要） | `#a1a1aa` | `#6e6e73` |
| `--accent` | `#0a84ff` | `#007aff` |
| `--divider` | `rgba(255,255,255,.08)` | `rgba(0,0,0,.08)` |
| 聚焦态 | 强调色描边 + `0 0 0 3px rgba(10,132,255,.35)` 外发光 | 同左 + 轻投影 |

**状态色（两套通用）**：运行绿 `#30d158` / 暂停琥珀 `#ffd60a` / 停止灰 `--text-2` / 危险红 `#ff453a`。

### 6.3 字体

- 字体栈：`-apple-system, "SF Pro Text", "PingFang SC", "HarmonyOS Sans SC", "MiSans", "Segoe UI", system-ui, sans-serif`
- 层级（十英尺可读性 + 扁平克制）：Tab 18px/600 · 卡片标题 20px/600 · 正文 16px/400 · 次要 13px/400

### 6.4 主题切换

- 三态：深色 / 浅色 / 跟随系统（`prefers-color-scheme`）
- 实现：`<html data-theme="dark|light">` 定义 CSS 变量；跟随系统走媒体查询默认分支
- 持久化到 `config.json`，切换即时生效（无需重启）

### 6.5 分辨率与缩放

- **UI 缩放（分辨率基准）**：720p / 1080p / 2K / 4K / 自动，本质是 UI scale factor，以 `rem` 基准整体缩放；物理像素由 HDMI 屏 EDID 决定（见 4.6 设置项详表）
- **画面采集**：帧率 5/10/15fps（模式 1）；缩放 原始 / 适配屏幕 / 自定义，沿用信箱模式黑边

### 6.6 沉浸模式

- 控制台 / 终端全屏：隐藏顶栏与 Tab 条，保留底部状态栏（毛玻璃：时间 + 连接状态点 + 退出提示）
