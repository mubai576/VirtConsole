## 三、焦点层（重点）

`FocusProvider` + `useFocusable` 统一收口方向键导航。
在此之前 4 个 Tab 各写一套导航与高亮，靠「单高亮不变量」断言兜底；收口后加视图不必重写导航。

### 三条组件层约定

**1. 焦点不用 `:focus`。**
组件收 `focused` 布尔属性，渲染 `.vc-focused`。DOM 焦点由 `FocusProvider` 托管，
这样一个视图内的高亮是**纯派生状态**，单高亮不变量才成立。

> 唯一例外是 `TextField` —— 输入框必须拿真实 DOM 焦点，否则按键进不去。
> 它在 `focused` 变化时自己 focus/blur，**调用方需同期挂起方向键导航**。

**2. `Slider` 不自己吃按键**，只导出 `nudge(value, dir, opts)`。
组件内再抢一层 `keydown` 会和 `FocusProvider` 打架。

**3. `NavigationBar` 同时输出新旧类名**：`mx-navitem` + `tab` / `focus` / `active`，
容器 `id="tabbar"`，保住测试选择器 `#tabbar .tab.focus`。**改这些类名必须同步改测试。**

### 焦点注册必须同步派发

`onFocus` **同步派发，不能用 `rAF`**。窗口未合成时 `rAF` 被节流甚至暂停，
`onFocus` 迟到会让「切 Tab 后立刻按键」落在旧状态上。
四视图常驻挂载 + `useLayoutEffect` 注册，派发时注册表必然就绪。

### 光标与激活态是两个 state

`current`（Tab 栏光标）与 `activeId`（已激活视图）**必须分开**。
合成一个会让 Tab 栏 ←→ 移动 `.active`，测试里按「差几个位置」推算按键次数就全错。

### 轮询回调不得回灌高亮

实时刷新的回调（如监控卡片就绪）必须**完全派生自 `(hasFocus, row, cidx, sub)`**，
`hasFocus` 要进依赖数组。否则离开 Tab 后下一次轮询会把 `.focused` 贴回去，
随机触发多高亮失败。不要依赖 `onBlur` 做一次性清理。

## 四、模态策略（偏离原方案，有意为之）

**模态保持命令式**（`lib/modal.js`），`Dialog.jsx` 组件存在但暂未使用。

原因：调用点全是 `if (!await showConfirm(...)) return;` 这类线性 async 流；
测试套件 G/H 有 20+ 场景断言 `.modal` / `.form-row` 的 DOM 结构与 inline `display` 显隐。
改成 React 声明式要给每个视图加状态机，且这些断言全得重写。

React 下「抹掉底层 `.focused`」失效（下次渲染会加回来），
故用 `lib/modalState.js` 做**深度计数**，由 `useFocusable` 读它让视图自行不渲染高亮。
这是「模态内单高亮」的实现方式。

模态用 **capture 阶段监听并 `stopPropagation`**，打开期间按键不漏到底层视图。

## 五、终端焦点与退出钩子

终端退出钩子必须由 `termActive` **单一 effect 同时派生**终端焦点与退出钩子。

历史 bug：钩子只在挂载 effect 里注册一次，首次 `Ctrl+Alt+Q` 用掉后重进不再注册，
第二次找不到钩子 → xterm 保住 DOM 焦点并吞掉后续全部按键 → 污染其后所有测试套件。

## 六、构建链

```bash
# 完整构建（前端 + Rust）
./scripts/install.sh build     # = npm ci && npm run build + cargo build --release -p vc-ui

# 只构建前端
cd ui/web && npm run build     # → ui/dist/
```

| 事项 | 说明 |
|---|---|
| `vite.config.js` 的 `base: "./"` | **必需**。Tauri 以本地文件（非 http）加载产物 |
| Node 版本 | 需 **≥ 20.19**（Vite 7 要求）。Debian 12 自带 Node 18 不够 |
| 为什么不写进 `BUILD_DEPS` | 装了 Debian 自带的 18 反而误导；改为运行时校验 major 版本并提示用 NodeSource 装 22.x |
| `cmd_install` | 只校验 `ui/dist` 是否存在，**不在装机时重建** |
| 产物不入库 | 避免产物与源码不同步（`dist` 已在 `.gitignore`） |
| 改前端后行为没变 | `touch ui/src/lib.rs` 或重新 `cargo build -p vc-ui` 强制重嵌 |

**vite 固定 7.3.6**：7.1.x 有 5 条 dev-server 高危告警（路径穿越 / `server.fs.deny` 绕过 /
WebSocket 任意文件读），同 major 补丁升级后 0 漏洞。
