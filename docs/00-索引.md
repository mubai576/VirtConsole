## 三、术语表

| 术语 | 含义 |
|---|---|
| **PVE** | Proxmox VE，宿主机虚拟化平台。真机实测 PVE 9.2 / Debian 13 |
| **十英尺 UI** | 电视/机顶盒式界面：远距离可读、方向键导航、零鼠标依赖 |
| **模式 1 / 2 / 3** | 三种 VM 画面采集路径。1=QMP screendump，2=dbus-display，3=IVSHMEM。见 [21](21-采集与输入.md) |
| **QMP** | QEMU Machine Protocol，走 Unix socket。**同一时刻只允许一个客户端连接** |
| **dbus-display** | QEMU `-display dbus`，经 D-Bus 导出画面与键鼠接口 |
| **Scanout / Update** | dbus-display 的像素事件：全帧 / 脏区域局部更新 |
| **沉浸层** | 全屏模式（VM 控制台、终端），隐藏 Tab 栏，统一 `Ctrl+Alt+Q` 退出 |
| **单高亮不变量** | 全屏最多 1 个 `.focused` + 1 个 Tab 栏高亮 + 1 个 active 视图。测试强制校验 |
| **实体 / 实体页** | 宿主机与各 VM 统一抽象为「实体」，共用同一套详情页模板 |
| **miuix** | HyperOS 风格 Compose 组件库。**无 Web 实现**，本项目手写移植其设计语言 |
| **spike** | 前置技术验证，只证明链路可行，不实现完整功能 |
| **kiosk** | Weston kiosk-shell，全屏独占 HDMI，无桌面会话 |

## 四、代码地图

```text
VirtConsole/
├── qmp-engine/          # QMP 协议库：连接、握手、命令、PPM 帧解析、键鼠映射
├── host/                # 已退役的 M1 色条终端（留目录备查，不在 workspace 内）
├── ui/                  # 主应用 vc-ui（Tauri 2）
│   ├── src/             # Rust 侧
│   │   ├── lib.rs       #   仅装配：模块声明 + State + invoke_handler（141 行）
│   │   ├── commands/     #   IPC 命令，按 State 依赖分文件（app/vm/capture/config/pve/term/browser）
│   │   ├── capture/     #   模式 2 采集：session/frame/keymap/dbus_input
│   │   ├── input.rs     #   输入路由：D-Bus 可用走 D-Bus，否则回退 QMP
│   │   ├── qmp.rs       #   模式 1 采集 + QMP 输入
│   │   ├── pve.rs       #   PVE REST 客户端（含 mock:// 后端）
│   │   ├── terminal.rs  #   宿主 PTY 会话
│   │   ├── browser.rs   #   多 Webview 标签管理
│   │   ├── config.rs    #   config.json 持久化
│   │   └── testmode.rs  #   VIRTCONSOLE_TEST 测试模式与看门狗
│   ├── web/             # 在用前端（Vite + React），见 31-前端架构
│   └── dist/            # 构建产物，frontendDist 指向此处（不入库）
├── spike-dbus/          # M2.5 探针 crate（dbus-display Listener 验证）
├── archive/             # 已删除方案的结论与替代路径（不可执行规范）
├── deploy/              # systemd 单元
└── scripts/             # install.sh / check.sh / remove.sh / spike-qemu-check.sh / dmabuf-probe.sh
```

## 五、常用命令

```bash
# 构建（前端 + Rust）
./scripts/install.sh build

# 单元测试
cargo test --workspace

# 全流程 E2E（默认 mock 后端，离线确定性）
VIRTCONSOLE_TEST=1 cargo run -p vc-ui; echo "exit=$?"   # 0 全过 / 1 有失败 / 2 看门狗超时

# 只跑指定套件
VIRTCONSOLE_TEST=1 VIRTCONSOLE_TEST_SUITES=vm,monitor cargo run -p vc-ui
```

详细说明与真机跑法见 [40-测试规范.md](40-测试规范.md)。
